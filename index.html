How to use

  1. Fill in the job. Title, location, seniority and must-have quals from the order. The role family is picked from the title; change it if wrong.
  2. Run Tier 1 first. Exact title, must-haves and a council anchor on fresh CVs (56 days).
  3. Widen only when thin. Under 10 good CVs, run Tier 2 (synonyms, one key qual, 180 days). Still under 8, run Tier 3 (same string, 365 then 730 days, wider radius).
  4. Narrow with context, not NOT. Too many results? Add a legislation, system or client term (s202, Northgate, EHCP) rather than exclusions.
  5. Start from a template. The Templates tab has Khalsa's own searches; Load one, then tweak.

Khalsa's rules

  • Always anchor public-sector roles: ( council or councils or "local authority" or "london borough of" or "local government" ).
  • Use long OR lists of title synonyms; recruiters name the same job many ways.
  • Narrow with context (legislation, systems, regulators), almost never with NOT.
  • CV age steps: 56, 90, 180, 365, 730 days.
  • Radius: admin 5–14 mi, finance and HR 11–20, care and catering 20–35, senior or niche UK-wide, hard-to-fill up to 200.
